# Unsent: The Micro-Confession Sprint

An entry for the [make.fun](https://make.fun) competition
[u-boothlord-unsent-the-micro-confession-sprint-8c6596ba](https://make.fun/c/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba).

`main.py` (Python 3.13, standard library only) writes one two-part
micro-confession to `/output/entry.txt`: a `To:` line naming who the
message was meant for, and the unsent line itself, exactly as it was
typed — a note to a teacher that stayed in drafts because the writer
was too ashamed to admit they had stopped writing.

Run it with `python3 main.py` (writes to `/output/entry.txt`), or
`python3 main.py <dir>` to write to `<dir>/entry.txt`.
